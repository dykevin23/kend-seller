readme 폴더 하위의 md 파일들을 모두 읽고 프로젝트 컨텍스트를 파악해줘.

우선순위 (반드시 읽을 문서):
- `readme/core/claudeReadme.md` — AI 작업 가이드 (최우선)
- `readme/core/readme-structure-guide.md` — 문서 구조/관리 규칙
- `readme/core/application-architecture.md` — 아키텍처
- `readme/core/auth-model.md` — 인증/인가 모델
- `readme/core/database.md` — DB 구조

기타 참고 문서:
- `readme/core/` 하위 나머지 도메인 문서
- `readme/changelog-kend.md`, `readme/changelog-seller.md`, `readme/changelog-native.md` — 최근 변경 이력
- `readme/active/` — 현재 진행 중인 작업 계획
- `readme/todo/` — 예정 작업 계획

파일을 읽은 후 현재 프로젝트 상황을 간략히 요약해줘.
